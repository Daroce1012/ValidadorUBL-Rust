# 🔍 Validador UBL - WebAssembly

## 📋 Descripción
Validador de documentos UBL (Universal Business Language) en formato XML usando WebAssembly.

## 🚀 Uso
1. Abrir `index.html` en el navegador
2. Hacer clic para seleccionar archivo XML
3. Hacer clic en "Validar Documento"
4. Ver resultado de la validación

## 📁 Archivos Principales
- `index.html` - Interfaz web principal
- `main.js` - Punto de entrada de la aplicación
- `app-controller.js` - Controlador principal
- `dom-manager.js` - Gestor de interfaz
- `file-handler.js` - Manejador de archivos
- `ubl-validator.js` - Validador WebAssembly
- `utils.js` - Utilidades auxiliares
- `styles.css` - Estilos de la aplicación
- `ejemplo_factura.xml` - Archivo de ejemplo
- `ejemplos_ubl/` - Carpeta con ejemplos de prueba

## 🧪 Casos de Prueba
La carpeta `ejemplos_ubl/` contiene 11 archivos de ejemplo:
- **3 archivos válidos** - Para probar validación exitosa
- **8 archivos con errores** - Para probar detección de errores
- **Documentación completa** - README.md e INDICE_EJEMPLOS.md

## ✅ Características
- **Validación UBL** - Elementos requeridos (Invoice, ID, IssueDate, AccountingSupplierParty)
- **WebAssembly** - Alto rendimiento de validación
- **Interfaz simple** - Fácil de usar
- **Responsive** - Móvil y desktop
